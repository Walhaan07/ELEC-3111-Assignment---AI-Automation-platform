An end-to-end AI Automation Platform designed as a flexible alternative to n8n. Built for ELEC 3111, this platform enables automated workflow creation by connecting event triggers, custom scripts, and external services through modular node execution.

Key Features & Core Nodes

Triggers & Webhooks: Scheduled triggers and real-time HTTP webhook handlers to initiate workflows.

HTTP & API Integration: Support for standard REST/HTTP requests to connect external web services.

Google Workspace Suite: Dedicated integrations for Google Docs, Sheets, Drive, and Gmail.

Code Execution Node: Environment to execute custom code logic within the workflow execution pipeline.

Benchmarking & Analysis: Architectural and feature comparison against n8n to evaluate performance, usability, and extensibility.
