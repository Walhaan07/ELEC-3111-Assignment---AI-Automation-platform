The words we will keep using

Most of the confusion in a project like this comes from words, not from ideas. These eight describe things you have already seen with your own eyes in n8n — we are only giving them their proper names so the rest of this document can be short.

WordWhat it means, plainlyWhere you met it in n8n
Workflow One complete automation, from the thing that starts it to the last thing it does. It is just a drawing: some boxes and some lines. Your weather automation. One tab, one name, one on/off switch.
Node One step in that drawing. A node takes some data in, does one job, and passes data out. Every node works the same way, whether it sends an email or adds two numbers. Every box you dragged from the panel on the left.
Trigger A special node with nothing before it. It is what starts a workflow — a clock reaching a certain time, or a message arriving from outside. Your Schedule Trigger. Also the Webhook node.
Item One single piece of data travelling between nodes — one row, one email, one order. Nodes always pass a list of items, even when the list has only one thing in it. The numbered rows in the OUTPUT panel when you clicked a node.
Canvas The big area where you drag boxes and draw lines between them. It is only a drawing tool — the canvas never runs anything itself. The grey grid that filled most of the n8n screen.
Execution
(a “run”)		 One occasion on which a workflow actually ran. Each run is recorded so you can look back at it: what came in, what each node produced, whether it worked. The Executions list, with green ticks and red crosses.
Expression A small piece of text inside a settings box, written between double braces, that gets replaced with real data just before the node runs. {{ $json.city }} — what appeared when you dragged a field into a box.
Credential A saved login for an outside service, stored once and reused by any node that needs it. Kept scrambled so that reading the database does not reveal it. The Credentials screen where you connected your accounts.
Why this matters more than it looksThree of these words carry the whole project. Node tells us what four of us will spend Weeks 8–10 writing. Item decides the shape of every piece of code we write, and cannot be changed later. And execution is the thing our database exists to remember. If those three are clear to everyone, the rest of this document is mostly detail.
