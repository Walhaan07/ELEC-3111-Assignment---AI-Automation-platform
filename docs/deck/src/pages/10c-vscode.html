What you need to know

Nothing at all. Every code block in Parts 2 and 3 is pasted into this one program, and this page is how it works.

Whenever this book shows a file name above a block of code, it means: open that file in VS Code and put this in it. Whenever it shows a $ prompt, it means: type that into the terminal at the bottom of VS Code. That is the whole convention.

1 · Activity bar

Five icons down the left. Top to bottom: Explorer (files), Search, Source Control (git), Run, Extensions. Click one to change what the panel beside it shows.

2 · Explorer

Your project's folders. This is where you create files: right-click a folder → New File, type the name with its extension, press Enter.

3 · Editor

Where the code goes. Each open file is a tab. Click into it, select all with Ctrl A, paste with Ctrl V, save with Ctrl S.

4 · Line numbers

When somebody says “line 42 is broken”, this is what they mean. Red squiggles under code are ESLint telling you something before you run it.

5 · Terminal

Open it with Ctrl ` (the key above Tab). Every $ line in this book is typed here — without the $.

6 · Status bar

Left: the git branch you are on — check it before you type. Right: errors and warnings. If it says main, stop and make a branch first.

The three shortcuts worth memorising Ctrl S save · Ctrl ` show or hide the terminal · Ctrl P jump to any file by typing part of its name. On a Mac use Cmd instead of Ctrl. Everything else you can click for.
