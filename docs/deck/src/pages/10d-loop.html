1.11

The loop you will repeat a hundred times

Who needs this page
all eightevery single day
What you need to know

Nothing. Six steps, the same six every time, whether you are changing one line or adding a whole node.

1

Make a branch before you touch anything

$ git pull # get everyone else's work first $ git checkout -b amy/webhook-node # yourname/what-you-are-doing

Check the bottom-left of VS Code: it should now show your branch name, not main.

2

Create the file, paste, save

1In the Explorer, right-click the folder this book names → New File
2Type the exact file name including the extension, press Enter
3Click into the editor, paste, then Ctrl S. Prettier reformats it as it saves — that is expected.
3

Run it and look at the result

$ npm run dev # leave this running in one terminal # open a SECOND terminal with the + button, and use that one for everything else
4

Prove it, before anyone else sees it

$ npm test # the checks for your part $ npm run lint # the same checks CI will run

If either is red, you are still on step 2. Pushing red work costs somebody else an hour.

5

Commit and push — with buttons, or with typing

1Click the Source Control icon (third down the left bar) — your changed files are listed
2Hover a file → + to stage it. Review the diff first: VS Code shows old and new side by side.
3Type a message in the box — what changed and why, not “update” — then click ✓ Commit
4Click Sync Changes (or Publish Branch the first time)
$ git add -A && git commit -m "add the webhook node" && git push -u origin HEAD
6

Open the pull request

1Open the repository on GitHub — a yellow bar offers Compare & pull request
2Title it like the commit; in the body say what you checked
3On the right, Reviewers → pick your pair (A1↔A2, B1↔B2, C1↔C2, D1↔D2)
4Wait for the green tick from CI, then Merge pull request → Delete branch
The two mistakes everyone makes onceWorking on main without noticing — check the bottom-left corner. And pushing before npm test passes, which turns your five-minute problem into somebody else's afternoon.
